# Envelope Budgeter

Una pequeña aplicación web para calcular el presupuesto mensual y controlar gastos por categorías como comida, utilidades y entretenimiento.

## Descripción

Envelope Budgeter permite:

- ingresar el ingreso mensual
- agregar gastos por categoría
- calcular el total de gastos
- ver si queda un saldo positivo o si se está por encima del presupuesto
- limpiar el formulario para empezar de nuevo

## Funcionalidades

- Agregar múltiples gastos a cada categoría
- Eliminar gastos individualmente con un botón
- Validación de entradas numéricas
- Cálculo de presupuesto restante
- Vista visual del estado: saldo restante o sobre presupuesto

## Tecnologías

- HTML
- CSS
- JavaScript vanilla

## Uso

1. Ingresa tu ingreso mensual.
2. Selecciona una categoría y agrega gastos.
3. Escribe el nombre y la cantidad de cada gasto.
4. Haz clic en "Calcular Presupuesto Restantante".
5. Revisa si tienes saldo positivo o si estás por encima del presupuesto.

## Nota

Este proyecto está pensado como una práctica de JavaScript vanilla para manejar formularios, eventos del DOM y cálculos básicos de presupuesto.
